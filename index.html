03 / 依據與算法

公式說明

A

溫度加速經驗式

Lₓ = L₀ · Bₜ(T₀ − Tₓ)/10

反推溫度：Tₓ,max = T₀ − 10 · logBₜ(Lreq/L₀)。範例：L₀ = 2,000 h、T₀ = 105°C、Bₜ = 2、目標 26,280 h，得到 67.84°C。

B

規格不含額定紋波（ripple）

Lₓ = L₀ · 2(T₀ − Tₓ)/10 · 2−ΔT/5

適用於廠商以額定電壓定義耐久規格的貼片／引線液態鋁電解電容。ΔT 是實際紋波（ripple）造成的內部溫升。此式採 Nippon Chemi-Con 的自熱修正係數；Bₜ 可調時僅替換周圍溫度項。

C

規格已含額定紋波（ripple）

Lₓ = Lᵣ · 2(T₀ − Tₓ)/10 · 2(ΔT₀ − ΔT)/5

適用於廠商以額定紋波（ripple）電流疊加直流電壓定義耐久規格的貼片／引線液態鋁電解電容。近似 ΔT = ΔT₀ · (Iₓ/I₀)²；額定紋波（ripple）已含在 Lᵣ 中，故以兩個自熱值的差修正。

使用前核對

  • 先查該料號的耐久規格條件、額定紋波（ripple）的頻率與溫度，以及廠商提供的 ΔT₀；不要把 5°C 當所有系列的通用值。
  • 多頻紋波（ripple）可用 Ieq = √Σ(If/Ff)² 換算；Ff 必須取自該系列型錄。若有量測內部溫升，優先用實測值。
  • 本工具的 B、C 式不涵蓋 snap-in、螺絲端子、高壓電壓修正，以及混合／固態聚合物的系列專用式；請用廠商工具或型錄。TDK 亦以系列壽命曲線和紋波（ripple）倍率求值。
  • 依 Nippon Chemi-Con 指引，低於 40°C 時估算以 40°C 計，超過 15 年的延伸外推不宜當成可保證壽命。高溫、頻繁充放電與超額紋波（ripple）須另核對規格。

01 / 電容損耗

損耗計算條件

每列一個頻率，可用逗號、空白或 Tab 分隔。填入電容支路的 RMS 電流，不能直接填 FFT 峰值。不同頻率按能量加總；同頻成分須先合成。

tanδ 填無單位比值，例如 10% 填 0.1。須與上方頻率及工作溫度相符。

漏電流請依實際電壓、溫度及通電時間取得；型錄上限代入會得到保守值。

用總損耗估算穩態內部溫升。外殼至周圍熱阻不能直接當作內部熱點熱阻；工作溫度下的 ESR 需另行核對。

03 / 公式與適用條件

電容損耗公式

A

單一 ESR

PAC = Irms² · ESR

ESR 用 Ω，電流用 A rms，結果為 W。mΩ 需乘 10⁻³。適用於單頻主導，或 ESR 在所含頻率範圍近似不變。使用該頻率及工作溫度的 ESR；ESR 不是阻抗幅值 |Z|。

B

多頻紋波分項加總

PAC = Σ Ik,rms² · ESR(fk)
Itotal,rms = √Σ Ik,rms²

每個頻率使用各自 ESR；假設穩態、不同頻率成分正交。型錄紋波電流的頻率修正係數，不等於 ESR 倍率。高頻與低頻 ESR 不同時，不能直接拿總 RMS 乘任意單一 ESR。

C

由 tanδ 換算

ω = 2πf；XC = 1/(ωC)
ESR = tanδ/(ωC)
PAC = Irms² · ESR

採串聯 C–ESR 模型，適用於低於自諧振、仍呈電容性的單頻條件。C 用 F，µF 乘 10⁻⁶。型錄 120 Hz 的 tanδ 不能直接用於開關頻率。

已知端電壓：
PAC = VAC,rms² · ωC · tanδ / (1 + tan²δ)

端 AC 電壓不含 DC。當 tanδ 很小時，近似為 V²ωCtanδ；工具保留分母修正，且不計 ESL。若 tanδ 已代表總等效損耗，不再加一次 ESR 損耗，以免重複計算。

D

漏電與內部溫升

PDC = VDC · Ileak
Ptotal = PAC + PDC
ΔT = Ptotal · Rθ,hotspot–ambient

漏電流 µA 乘 10⁻⁶。溫升為指定熱阻與固定電氣參數的穩態估算；不自動迭代 ESR 隨溫度變化。僅知道額定紋波電流，無法唯一求出損耗 W，仍需要 ESR、tanδ 或可信熱資料。
